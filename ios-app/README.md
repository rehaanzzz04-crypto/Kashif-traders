# Kashif Traders iOS / TestFlight

Native iOS wrapper for the official ERP at https://kashif-traders.vercel.app/.

- App: Kashif Traders
- Bundle ID: com.kashiftraders.erp
- Version: 1.0.0 (build 1)
- Minimum iOS: 16.0
- Persistent WKWebView data store preserves cookies, local storage, IndexedDB and web cache used by the ERP.
- Camera and Photo Library usage descriptions are configured for bill/payment attachments.
- External links open outside the app; Kashif Traders/Vercel pages remain in the app.

The GitHub validation workflow builds for iOS Simulator with code signing disabled. A signed TestFlight archive still requires an Apple Developer/App Store Connect team and signing credentials.
